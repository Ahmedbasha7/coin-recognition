# Разпознаване на монети в обръщение (Компютърно зрение)

Курсова работа: откриване и разпознаване на български монети със Python и OpenCV.

## Необходими операции (по условие)
1. Създаване на изображения на монетите
2. Обработка до ясно разграничаване на търсените елементи
3. Откриване на кръгъл обект в изображението
4. Сравняване с еталонните изображения при съобразяване с ротация

## Статус
- [x] Стъпка 1: откриване на кръгове (`src/detect_circles.py`)
- [ ] Стъпка 2: обработка (праг, контури) и изрязване на всяка монета
- [ ] Стъпка 3: еталонни изображения и сравняване с ротация
- [ ] Стъпка 4: определяне на номинала и сбор на стойността
- [ ] Стъпка 5: оценка на точността, документация

## Инсталация
    pip install -r requirements.txt

## Пускане (стъпка 1)
    python src/detect_circles.py images/moneti_2lv.jpg --min-radius 100 --max-radius 170 --min-dist 200
    python src/detect_circles.py images/moneti_present_all.jpg --min-radius 20 --max-radius 48 --min-dist 40

Резултатът (снимка с оградени монети) се записва в папка `output/`.

## Как работи стъпка 1
1. Снимката се превръща в сива скала и се размазва (`medianBlur`), за да намалее шумът.
2. `cv2.HoughCircles` търси кръгове. Намира се най-добрият център и радиус за контурите в снимката.
3. Намерените кръгове се чертаят върху копие на снимката и се номерират.

Радиусите и разстоянието между центровете зависят от размера на монетите в снимката, затова се подават като параметри.
